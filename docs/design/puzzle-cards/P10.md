# P10. Water That Refuses Level

**Room:** R07 Wet Laboratory, view A. Close-up `c_tilt_rack` (rack that tips one jar through a fixed quarter-turn; a test diagram card that draws the surface against three reference lines: GRAVITY, JAR, DATUM).

**Tide:** IV. Parallel with P11. Target 4 minutes.

## Requires

`p09_complete`.

## Evidence

| Evidence | Where |
| --- | --- |
| Reference card: "A valid sample: surface follows the station datum, independent of vessel." | Pinned above the reference socket, view A. |
| The brass datum line on the wall, labelled DATUM and drawn on the test card. The datum is tilted 8 degrees off true level (the station was built on it). | View A wall; `c_tilt_rack`. |
| Jars A, B, C, sealed, each half full of seawater. | Tilt rack. |

## Solution

Tip each jar once (**TEST**). Results, always the same: **A** stays level with true gravity; **B** stays fixed to the jar walls (tilts with the jar); **C** stays parallel to the brass datum. Place **C** in the reference socket (commit).

## Wrong answers

Placing A: "This one follows gravity. The card wants the datum." Placing B: "This one follows the jar." The test diagram shows exactly which reference each surface followed, by line style and label. Untested jars can be placed; the socket refuses with the same lines and suggests testing.

## Outputs

- Flag `p10_complete`. Evidence `datum_target` ("Datum reading stable. Stair pressure target: 2." printed on a tag that drops from the socket).

## Consumed

Nothing in inventory. Jar C stays installed (room-local).
