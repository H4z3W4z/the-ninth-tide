# P13. The Weight of an Absence

**Room:** R07 Wet Laboratory, view B. Close-up `c_balance` (balance pan, empty control tray, ADDRESS key, RELEASE key, RECORD key, a three-cell strip that prints readings for UNATTENDED, ADDRESSED, RELEASED).

**Tide:** V. Target 5 minutes.

## Requires

`p12_complete`.

## Evidence

| Evidence | Where |
| --- | --- |
| Three sample cards, tagged by specimen number only (no letters anywhere on the tags, the cards or in `c_balance`): **27-03** (seawater), **27-11** (a stoppered tube, contents not given), **27-19** (foundation stone), each across UNATTENDED / ADDRESSED / RELEASED, readings left blank for the balance. Stands and cards run in number order. | Sample rack, view B; `c_balance`. |
| Nora's 1927 kitchen work card carries her specimen number, 27-11 (R05). | By the range, R05. |
| Specimen register: eight staff cards. Only Nora Bell's carries the stamp "SPECIMEN 27-11". | Register drawer, view B. |

## Solution

Place specimen **27-11** on the balance. In the register select **NORA BELL** (this takes `nora_register_card`) and press ADDRESS. Press RELEASE. The strip reads **0 / 3 / 0**. Press **RECORD** (commit).

## Wrong answers

- Wrong name addressed: flat trace 0 / 0 / 0 and "NO CORRESPONDENCE" on the strip.
- 27-03 or 27-19 on the pan: their printed constant readings; "Environmental. It doesn't answer to a name."
- RECORD before release: "RECORD INCOMPLETE."
