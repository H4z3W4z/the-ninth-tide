# P13. The Weight of an Absence

**Room:** R07 Wet Laboratory, view B. Close-up `c_balance` (balance pan, empty control tray, ADDRESS key, RELEASE key, RECORD key, a three-cell strip that prints readings for UNATTENDED, ADDRESSED, RELEASED).

**Tide:** V. Target 5 minutes.

## Requires

`p12_complete`.

## Evidence

| Evidence | Where |
| --- | --- |
| Three sample cards: **N** "0 dr → 3 dr → 0 dr", **W** (seawater) "0 → 0 → 0", **F** (foundation stone) "2 → 2 → 2", each across UNATTENDED / ADDRESSED / RELEASED. Each card has a sample stamp. N's stamp: "SPECIMEN N-27". | Sample rack, view B. |
| Specimen register: eight staff cards. Only Nora Bell's carries the stamp "SPECIMEN N-27". | Register drawer, view B. |

## Solution

Place sample **N** on the balance. In the register select **NORA BELL** (this takes `nora_register_card`) and press ADDRESS. Press RELEASE. The strip reads **0 / 3 / 0**. Press **RECORD** (commit).

## Wrong answers

- Wrong name addressed: flat trace 0 / 0 / 0 and "NO CORRESPONDENCE" on the strip.
- W or F on the pan: their printed constant readings; "Environmental. It doesn't answer to a name."
- RECORD before release: "RECORD INCOMPLETE."

## Outputs

- Flag `p13_complete`. Item `nora_register_card`. Evidence `nora_mass_trace`.
