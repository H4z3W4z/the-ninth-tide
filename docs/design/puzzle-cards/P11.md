# P11. Something Still Breathing

**Room:** R08 Machine Room. Close-up `c_valves` (four labelled toggles SUPPLY, GATE, RETURN, INDEX; PUMP lever; a PREVIEW key that lights the active circuit on the drawing).

**Tide:** IV. Parallel with P10. Target 4 minutes.

## Requires

`p09_complete`.

## Evidence

| Evidence | Where |
| --- | --- |
| Maintenance drawing: a valid loop drawn from SUPPLY through GATE and back through RETURN, with INDEX shown capped and marked "SEALED. NEVER FEED." | Above the valve board. |
| Pipes labelled SUPPLY, GATE, RETURN, INDEX at each toggle. | Valve board. |

## Solution

**SUPPLY open, GATE open, RETURN open, INDEX closed.** Engage **PUMP** (commit).

## Wrong answers

PREVIEW (and every PUMP attempt) traces the active circuit on the drawing in a dashed overlay and names the fault: "DEAD END AT GATE" (RETURN closed), "NO SUPPLY", "DIVERTED TO INDEX" (INDEX open; the pump refuses to engage and Ada: "It would feed the sealed line."). No burst pipe, loss or danger.

## Outputs

- Flag `p11_complete`. Evidence `reference_respiration`.
- O04 available.

## Consumed

Nothing.

## Hints

1. "The machine room's valve board routes pressure. The drawing above shows the loop."
2. "Pressure has to go out through the gate and come back, without reaching the sealed line."
3. "SUPPLY open, GATE open, RETURN open, INDEX closed. Then the pump."

## Notebook

`reference_respiration`: "With the gate loop running, one belt stopped. The diaphragm kept breathing without it. Under the belt, a nameplate: REFERENCE RESPIRATION."

## Reveal and dread

The pump takes up with a heavy, satisfying thump and the gate gauge (seen later at R11) reads powered. Then one belt winds down and stops. The diaphragm does not. Its next inhalation pulls fine dust horizontally across the floor toward it (`motion`; still: dust streaks). The plate under the belt reads REFERENCE RESPIRATION.

All 16 toggle states; INDEX open never engages; each fault name correct; repeated PUMP idempotent.
